# 开发路线

以规范 §53 为准，以下为任务组织，不改变 V1 范围。不预设每个里程碑恰好一周。

| 里程碑 | 交付 | 完成门槛 | 当前状态 |
|---|---|---|---|
| M0 | 包结构、启动、设置、日志、CI、pytest、空主窗口 | 安装、启动、测试；最小人工验收 | 实现与双平台 CI 通过，待人工验收 |
| M1 | Project/Hierarchy/Region、基础拓扑、工程 IO、原子保存、迁移、最近工程 | 无损往返与失败保护 | 第一批模型/校验与双平台 CI 通过；IO 待开始 |
| M2 | 欢迎页、新建向导、停靠面板、画布坐标、缩放平移、选择 | 创建空工程并导航 | 待开始 |
| M3 | 多边形、手绘、属性创建、树同步、校验、撤销 | 合法顶级区域编辑 | 待开始 |
| M4 | 共享边、切分、子区域、合并、飞地、邻接 | 无缝划分六省 | 待开始 |
| M5 | 顶点、吸附、平滑、简化、自然化、复杂撤销 | 共享边安全自然化 | 待开始 |
| M6 | 属性、数据表、自定义字段、配色、标签、图例、标题 | 完整彩色行政地图 | 待开始 |
| M7 | 图像/矢量/数据导出、导入、自动保存、恢复、备份 | 端到端工作流闭环 | 待开始 |
| M8 | 性能、高 DPI、异常、打包、回归、用户指南 | AC-01–AC-15 和最终交付清单全部通过 | 待开始 |

## 每轮流程

1. 读取实际提交和 CI，优先处理未完成工作和阻断 Bug。
2. 向用户给出对应条款、范围和验收方法，等待本轮批准。
3. 完成小批次实现，测试和检查，提交可恢复检查点。
4. 记录完成/未完成、已知问题、准确命令和下一步。

## 每周验收

准备阶段版本、启动方式、实际截图、测试结果、验收步骤和已知问题。
由用户实际体验并反馈；不将每周验收等同于全部 V1 功能完成。
本轮只交付 M0；可编辑地图和 Windows 正式构建在对应里程碑交付。
