## 当前交付

## Windows 10/11 人工验收

1. 创建三个相邻同级区域并批量合并。
2. 撤销/重做并保存重开。
3. 验证区域属性仍为一个树节点。
4. 使用后续部件 UI 添加岛屿或飞地，确认多个面同时选择和保存回读。
