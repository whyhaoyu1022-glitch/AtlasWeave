# M4-04 拓扑编辑扩展验收

## 当前交付

本批在 M4-03 基础上支持两个或多个相邻同级区域的批量真实合并，保留首个区域 UUID，隐藏其余旧对象并从共享边拓扑验证合并前置条件。

## 自动化证据

- `ruff check .`：通过。
- `ruff format --check .`：通过。
- 完整 `pytest -q`：156 项通过。
- 覆盖批量合并面积、UUID、旧对象隐藏、共享边和非法合并。
- Windows/Linux CI：提交后填写实际运行链接。

## Windows 10/11 人工验收

1. 创建至少三个相邻同级区域。
2. 多选区域并执行“编辑 → 合并相邻区域”。
3. 检查合并面积、边界、树、属性和 UUID。
4. 撤销和重做，确认完整恢复。
5. 尝试合并不相邻、不同层级、锁定和带子区域对象，确认拒绝。
6. 保存、关闭并重新打开，确认工程一致。
