# M3-02 自由手绘区域创建验收

## 范围

本批实现按住鼠标左键拖动采样真实世界坐标，简化并闭合轨迹，通过真实区域命令创建顶级区域。逐点多边形绘制仍保留；自由手绘、逐点绘制和平移工具互斥。

## Windows 10/11 人工验收

1. 创建或打开一个可写 `.atlasweave` 工程。
2. 选择“视图 → 自由手绘”或按 `F`。
3. 在画布内按住左键拖出一个凹多边形，松开鼠标。
4. 输入区域名称和类型并确认。
5. 检查画布、区划树、属性面板、状态栏面积和操作日志。
6. 再次绘制自交轨迹，确认创建被拒绝且轨迹仍保留。
7. 绘制越界、过小面积和与已有区域重叠的轨迹，确认有明确提示。
8. 在高 DPI 显示器上重复步骤 2–7，确认工具栏、状态栏和对话框可读。
9. 保存、关闭并重新打开工程，确认区域几何和名称保持一致。
