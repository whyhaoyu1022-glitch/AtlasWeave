# M2 第五批验收：真实区域选择与树同步

## 自动化证据

- 画布读取 `Project.regions` 与 `Project.topology` 的真实面数据，按真实几何绘制、命中和计算面积。
- 单击替换选择；Ctrl+单击切换选择；空白处清除选择。
- 左向右框选完整包含的区域，右向左框选相交区域；不可见区域不参与画布命中。
- 区划树选择会定位画布区域，画布选择会同步树节点和属性面板；锁定区域保留选择和查看能力。
- 状态栏显示已选区域数量和几何面积；没有生成假区域或占位数据。

## 对应规范

- §12、§13.2–13.3：真实面数据、区域显隐与选择行为。
- §17.3–17.4：画布选择反馈、树与画布同步。
- §33.3、§51.2：数据来自工程拓扑，异常几何不静默伪造。
- §53 M2：可用工程导航与选择批次。

## 自动化验收方法

```sh
uv tool run --from ruff==0.15.1 ruff check atlasweave tests
QT_QPA_PLATFORM=offscreen uv run --frozen --extra dev pytest -q
uv build --no-build-isolation
uv run --frozen --extra dev python scripts/verify_wheel.py
```

专项测试覆盖真实方形拓扑命中、面积、选择信号、不可见区域过滤、鼠标单击和真实几何框选；窗口测试覆盖停靠工作区接入。

## 人工验收（Windows 10/11）

1. 打开含真实拓扑区域的 `.atlasweave` 工程，单击区域确认高亮、属性和状态栏数量/面积更新。
2. 按住 Ctrl 单击两个区域，确认多选；点击空白处确认清除。
3. 从左向右拖框确认只选中完整包含区域；从右向左拖框确认相交区域也被选中。
4. 点击区划树中的区域、层级和工程节点，确认画布与属性面板同步。
5. 隐藏一个区域后确认画布无法命中；锁定区域仍可选择和查看，编辑能力留待命令批次。
