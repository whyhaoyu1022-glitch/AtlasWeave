# M1 第二批验收：工程文件 IO

用户于 2026-10-12 晚间批准本批计划；范围为 §33.1–33.6、§31.2、AC-01/13/15 的服务层基础。主窗口打开/保存、自动保存、崩溃恢复和未保存标记仍属于后续 UI/恢复批次。

## 自动化证据

- `tests/test_project_io.py`：完整 ZIP 成员、真实 PNG、拓扑/属性/扩展往返、附件保留；
- 原子保存失败保留原文件、清理临时文件；三份手动备份复制轮换；
- 高版本只读保护和新路径另存；迁移注册表的单向历史；
- 最近工程的上限、置顶、原子写入、移除与损坏恢复；
- 完整回归同时包含 M0 与 M1 第一批。

执行：`uv run --frozen --extra dev pytest tests/test_project_io.py -q`。
每次保存都会复读临时 ZIP 并检查 CRC；服务层验证不等同于 GUI 验收。Windows 实机继续执行 M0 清单，M2 接入菜单后再执行端到端 AC-01。
