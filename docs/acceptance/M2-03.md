# M2 第三批验收：四步新建工程向导

## 自动化证据

- 向导包含基本信息、世界尺寸、行政层级、完成四步，创建前通过 `ProjectStore` 的真实归档校验。
- 文件名清理 Windows 非法字符；宽高范围为 1–1,000,000 km；层级限制为 1–10 层且名称不重复。
- 创建成功后才设置当前工程和最近工程；失败不会留下半成品工作区状态。

## 人工验收（Windows 10/11）

1. 从欢迎页点击“新建工程”，逐页验证下一步、上一步和取消。
2. 在尺寸页点击三个预设，确认不会覆盖名称、作者或说明。
3. 在层级页添加、删除、上下移动层级，验证不能删除最后一层。
4. 创建后确认目标目录存在 `.atlasweave` 文件；关闭应用后从最近工程重新打开，核对说明、作者和层级。
5. 检查空工程画布、缩放和平移仍可用；绘制与编辑不应被误认为本批已完成。
