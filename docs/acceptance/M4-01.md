# M4-01 真实子区域切分与共享边验收

## 范围

本批支持选择一个无洞的简单父面，用一条穿过父边界的直线切分为两个真实子区域。父区域保留为隐藏的真实父记录，子区域拥有正确层级和 `parent_id`，共享切分边只保存一份。

## Windows 10/11 人工验收

1. 创建或打开包含至少两个层级的可写工程。
2. 创建一个简单的顶级父区域并选中它。
3. 选择“视图 → 切分区域”或按 `S`，按住鼠标左键拖过父区域后松开。
4. 输入两个子区域名称和类型并确认。
5. 检查父区域、子区域、区划树嵌套、画布、面积和属性面板。
6. 确认两个子区域之间没有空隙或重叠，共享边没有双线。
7. 使用 `Ctrl+Z` 撤销，确认子区域和拓扑恢复；使用 `Ctrl+Shift+Z` 重做。
8. 绘制不穿过父边界、自交或导致无效结果的切分线，确认拒绝且不会留下半成品。
9. 在高 DPI 显示器上重复上述流程，确认工具栏、对话框和状态栏可读。
10. 保存、关闭并重新打开工程，确认父子关系和边界保持一致。
