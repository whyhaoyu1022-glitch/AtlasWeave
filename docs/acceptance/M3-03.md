# M3-03 区域创建撤销与重做验收

## 范围

本批把逐点绘制和自由手绘创建接入 `QUndoStack`，撤销和重做恢复完整不可变工程快照、拓扑对象和选择状态。选择、缩放、平移、面板开关不进入撤销栈。

## Windows 10/11 人工验收

1. 创建或打开一个可写工程。
2. 使用逐点绘制创建一个顶级区域，再使用“编辑 → 撤销”或 `Ctrl+Z`。
3. 确认区域、拓扑、画布、树和属性面板恢复到创建前状态，标题星号消失。
4. 使用“编辑 → 重做”或 `Ctrl+Shift+Z`，确认区域几何、UUID、面积和选择状态恢复。
5. 保存工程后再创建区域，撤销到保存点，确认标题不显示未保存星号。
6. 撤销后创建新区域，确认原来的重做分支被清理。
7. 重复自由手绘创建流程，确认同样支持撤销和重做。
8. 在高 DPI 显示器上检查菜单、工具栏、快捷键提示和状态栏布局。
