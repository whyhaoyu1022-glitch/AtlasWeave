## 最小人工验收（待用户在 Windows 实机执行）

1. 根据 README 安装并启动，确认中文标题、浅色界面、状态栏“就绪”。
2. 调整窗口大小和位置，退出后重开，确认恢复。
3. 帮助 → 关于，核对版本、Python、PyQt 和 Qt 信息。
4. 帮助 → 打开日志目录，确认本地日志可查看；不上传日志。
5. 使用文件菜单退出，确认没有残留窗口。
6. 在 100%、125%、150%、200% 缩放下检查文本与菜单；小于规范最小窗口的显示器需单独记录。
