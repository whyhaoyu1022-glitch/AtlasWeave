# M4-03 拓扑切分、合并与邻接验收

## 范围

本批在 M4-02 的多段切分基础上，增加两个相邻同级简单区域的真实合并、共享边校验、拓扑邻接查询和撤销/重做。

## 自动化证据

- `ruff check .`：通过。
- `ruff format --check .`：通过。
- 完整 `pytest -q`：155 项通过。
- 合并专项覆盖共享边、并集面积、UUID 保留、旧对象隐藏、邻接更新和非法合并。
- Windows/Linux CI：提交后填写实际运行链接。

## Windows 10/11 人工验收

1. 创建两个具有真实共享边的同级区域。
2. 选中其中一个区域，确认属性面板显示邻接数量。
3. 同时选中两个相邻区域，执行“编辑 → 合并相邻区域”或 Ctrl+M。
4. 检查合并后边界、面积、UUID、树、画布和邻接数量。
5. 撤销和重做，确认两个区域和共享边完整恢复。
6. 尝试合并不相邻、不同层级、锁定或有子区域的对象，确认拒绝且无半成品。
7. 保存、关闭并重新打开，确认拓扑和区域关系保持一致。
8. 在高 DPI 下检查菜单、属性面板和状态提示。
