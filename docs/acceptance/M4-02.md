# M4-02 多段切分预览与层级安全验收

## 范围

本批将 M4-01 的单次二分扩展为：对无洞、无现有子区域的简单父面使用开放折线切分，预览两个或更多合法结果，确认后一次性创建同一父级下的下一级真实子区域。已有子区域、多部件父面和飞地仍会明确拒绝，不生成半成品。

## Windows 10/11 人工验收

1. 创建至少三个行政层级和一个无洞的顶级父区域。
2. 选择“视图 → 切分区域”或按 `S`，绘制穿过父边界的折线。
3. 确认画布显示临时结果面、结果数量和最小面积摘要。
4. 取消命名对话框，确认正式工程、区划树和未保存状态均不改变。
5. 重新绘制并确认，为每个结果填写不同名称。
6. 检查所有子区域使用紧邻下一级层级、同一 `parent_id`，没有缝隙或重叠。
7. 检查内部共享边只显示一条，撤销和重做恢复完整前后状态。
8. 再次尝试切分已有子区域的父面，确认明确拒绝且没有半成品。
9. 在 100%、125%、150% 和 200% 缩放下重复预览、命名和确认。
10. 保存、关闭并重新打开，确认几何、层级、属性和拓扑保持一致。
