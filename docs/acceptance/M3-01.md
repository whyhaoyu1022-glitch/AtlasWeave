# M3 第一批验收：多边形绘制与顶级区域创建

## 自动化证据

- 画布提供真实绘制模式：单击添加世界坐标顶点，点击首点闭合，右键/Backspace 删除最后一点，Esc 取消。
- 草稿使用真实 `QPointF` 世界坐标，显示预览折线、顶点和闭合前的当前边。
- 自交、面积过小、超出世界边界和与既有区域重叠会阻止提交，并在问题面板显示原因。
- 元数据确认后通过 `create_top_level_region` 不可变命令生成真实 Vertex/Edge/HalfEdge/Ring/Face/Region 快照。
- 新区域保存到 `.atlasweave` 后重新读取，拓扑和属性保持一致；锁定/只读工程不能进入绘制。
- 树、画布、属性面板和操作日志在创建成功后同步。

## 对应规范

- §13.1：多边形逐点绘制、闭合和取消。
- §14：自交、面积、越界和重叠校验。
- §17、§48：绘制工具状态、键盘行为和预览反馈。
- §33.3、§47：真实拓扑提交、保存回读和数据一致性。
- §51.1–§51.2：命令、工程往返与 UI 交互测试。

## 自动化验收方法

```sh
uv tool run --from ruff==0.15.1 ruff check atlasweave tests
uv tool run --from ruff==0.15.1 ruff format --check atlasweave tests
QT_QPA_PLATFORM=offscreen uv run --frozen --extra dev pytest -q
uv build --no-build-isolation
uv run --frozen --extra dev python scripts/verify_wheel.py
```

专项测试覆盖草稿点、闭合信号、取消/删点、合法三角形命令、重叠/越界拒绝和工程保存回读。

## 人工验收（Windows 10/11）

1. 新建工程，选择“视图 → 绘制区域”（或按 `D`），绘制凹多边形并点击首点闭合。
2. 在确认对话框填写区域名称和类型，确认区划树、画布高亮、属性面板和操作日志同步。
3. 使用 Esc 取消草稿，使用右键或 Backspace 删除最后一点。
4. 绘制自交轮廓、越界轮廓和与已有区域重叠的轮廓，确认均被阻止且问题面板给出原因。
5. 保存、关闭、重新打开工程，确认区域几何和名称仍存在；只读工程不能启用绘制。
