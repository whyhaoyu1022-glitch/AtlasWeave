# M2 第四批验收：停靠工作区与工程导航

## 自动化证据

- 主窗口使用三个真实 `QDockWidget`：左侧工程与区划、右侧属性与样式、底部问题与数据。
- 左侧区划树读取 `Project.hierarchy_levels` 和 `Project.regions`；空工程不生成区域节点。
- 右侧属性面板显示工程名称、作者、说明、世界尺寸和层级数；选中真实区域时显示区域属性。
- 底部提供问题、区域数据和操作日志标签页；面板可关闭、浮动，并可从“视图 → 面板”恢复。
- `WindowSettings` 保存窗口几何和 Qt 停靠布局；“重置工作区布局”恢复默认停靠位置。

## 人工验收（Windows 10/11）

1. 创建或打开 `.atlasweave` 工程，确认左、右面板显示真实工程信息。
2. 在“视图 → 面板”关闭、恢复和浮动各个面板，确认中央画布仍可缩放、平移。
3. 调整左、右、底部面板尺寸，退出并重新启动，确认布局恢复。
4. 执行“重置工作区布局”，确认左、右面板回到默认位置，底部面板按规范保持折叠。
5. 在区划树中点击工程或层级，确认状态栏反馈当前节点；空工程不出现虚假区域。
