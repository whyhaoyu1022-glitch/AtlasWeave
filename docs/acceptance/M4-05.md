# M4-05 交互式顶点编辑验收

## 当前交付

本批新增顶点编辑模式。用户选中区域后按 V，画布显示真实拓扑顶点；拖动共享顶点会提交统一命令，关联面同步变化，非法结果保持原工程。

## 自动化证据

- `ruff check .`：通过。
- `ruff format --check .`：通过。
- 完整 `pytest -q`：160 项通过。
- 命令层覆盖共享顶点移动、插点、删除和非法几何。
- CI 运行链接：提交后补充。

## Windows 10/11 人工验收

1. 创建两个共享边区域并选中。
2. 按 V，确认顶点控制点清晰可见。
3. 拖动共享顶点，确认两侧同步且无缝隙。
4. 尝试拖动造成自交、越界、重叠的点，确认拒绝。
5. 确认 Ctrl+Z/Ctrl+Shift+Z 和保存重开。
6. 在高 DPI 下检查控制点、状态提示和属性面板。
